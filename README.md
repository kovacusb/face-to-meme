# face-to-meme

Detects the expression on someones face. Measures blendshapes and landmarks using mediapipe video solution privided by Google AI Edge.

Uses a small model to predict an expression given the blendshapes of a specific frame and shows an image trying to match the expression detected in the webcam.
IMPORTANT!
The latest python version it works with is Python 3.14.7. 
Required dependences can be installed through pip install "requirements.txt" -r. 

Memes can be modified but keep the names, eg: happy.jpeg, angry.jpeg
